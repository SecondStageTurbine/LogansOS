# Open Threads & Banked Debts Register

The single tracked home for **deferred / banked / follow-on** items — the things that are
correctly *not done yet* but must not rot into "glossed over." Created from the 2026-06-17 PM audit,
which found the work sound but the *tracking* diffuse (items scattered across ADRs, THINKs, and the
governance docs). This register is the third small governance ledger, peer to:

- `docs/complexity-governance.md` — the **technical invariant** ledger (I-1…I-15).
- `docs/STRATEGIC-HONESTY-LEDGER.md` — the **strategic-claim** ledger (proven / structural / measurable / bets / kill-conditions).
- **this file** — the **open-thread / banked-debt** register.

**Maintenance:** PM-owned, re-audited at **every phase close** (the Rule-4 consolidation cadence). An
item is removed only when *done* (with the closing evidence) or *consciously dropped* (with a reason).
A stale, un-updated register is a fired **KC-5** (the discipline failing silently) — same standing as
a stale invariant ledger.

**Status key:** OPEN (not started) · IN-FLIGHT (dispatched/being addressed) · BANKED-GATE (a rule that
gates a *future* dispatch; nothing to do until that dispatch) · DEFERRED (legitimately later) ·
RESOLVED (kept briefly with closing evidence, then removed at next audit).
