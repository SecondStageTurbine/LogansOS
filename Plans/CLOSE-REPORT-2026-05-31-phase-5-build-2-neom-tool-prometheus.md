## Format Constants (hard-coded from ADR-028)

- Magic: `b"NEOM"`, Version: `1`, Header size: `96`
- TensorEntry: `96` bytes, NodeEntry: `48` bytes, IoEntry: `80` bytes
- Dtype ABI: `F32=0 .. Bool=6` (matches kernel `ai/tensor_logic.rs`)
- OpCode set: `Identity=0 .. Transpose=11` (ADR-028 D3)
- Weight blob: page-aligned (4096), per-weight: 64-byte aligned
