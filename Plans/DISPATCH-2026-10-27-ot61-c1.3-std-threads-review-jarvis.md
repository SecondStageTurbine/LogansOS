# DISPATCH (relay #99): cross-family review of OT-61 C1.3, std threads and exit_group (#158) → Jarvis

**MODEL:** GPT-6.1-Sol. **EFFORT:** high. C1.3 changes thread lifecycle and teardown. A worker's `SYS_EXIT` now ends
the whole process, reusing the fault-kill path's sibling drain. That's SMP-core code, Claude-authored (S4), so it
needs a cross-family lens (CLAUDE.md, AAG for the concurrency core). **Do this right after relay #89 (C1.2), before
#92 and #97.** It builds directly on C1.2.

**Type:** review, post-merge (merge on green, review after, revert-first on a confirmed FAIL).
**Deliverable:** one pushed RETURN. **Reviewed SHA:** `908b35b5`, #158's squash on main (PR head `a3031115`). Gate: batch 6,
run `40457391685`, all jobs green.

**What it does.**
- **userland std:**
  - `std::thread` is built on the C1 thread syscalls.
  - std's futex Mutex/Condvar/RwLock/Once/Parker run over `SYS_FUTEX_WAIT/WAKE`, and `thread_local!` uses the key
    layer. One shared `tls.rs` serves both std and libneo.
  - `Instant` is monotonic. `SystemTime` is unsupported.
- **The A4 gate.** `asm!` with a second template string is refused. There's one sanctioned `fn tcb`, and an ELF
  backstop requires every FS/GS-relative instruction to sit inside `tls::tcb`.
- **The kernel, under `browser-runtime`:**
  - When siblings are live, `SYS_EXIT` ends the whole process (exit_group).
  - The fault kill's tail moved into `retire_process_from_current_thread`, and exit_group reuses it.
- **A known limit (CP-86, OPEN, fixed in C1.3b).** A sibling Running in ring 3 on another CPU at exit isn't stopped,
  so the process hangs. The PR claims memory stays safe.

## Checklist

Answer each item PASS or FAIL with `file:line`. For any FAIL, give a concrete input or interleaving.

1. **The CP-86 memory-safety claim.** Check that a sibling still Running on another CPU keeps the process's `Pmap`
   and its own `Thread` alive until it's off-CPU and reaped. The PR cites:
   - `sched/thread.rs:98,123,227`;
   - `scheduler.rs:1601,2597`;
   - `process.rs:590,2492`.
   Say whether any path frees the `Pmap`, the `Process` or the thread's kernel stack while `live > 0`. That includes
   the exit_group path, the fault kill, and a `sys_wait` reaper on another CPU. **If this claim is wrong, C1.3 is
   reverted.**
2. **exit_group vs join, futex and IPC parks.**
   - When a worker exits the process while siblings are Ready, futex-parked, IPC-parked or in `sys_wait`, each is
     drained exactly once.
   - No sibling is woken into a process that's already retired, and the joiner doesn't park after the drain.
   - Compare with the C1.1 force-kill-vs-join window (Ready→Running).
3. **The extracted tail.** `retire_process_from_current_thread` runs the same statements, in the same order, as the
   fault kill did before. The fault kill's behaviour is unchanged. The PR says the off-kernel `.text` differs only in
   `fault_kill_current_user_exception`, so confirm the code matches.
4. **Single-threaded exit is unchanged.** A process with no live siblings exits exactly as before, with and without
   `browser-runtime`.
5. **std's futex sync.**
   - Mutex, Condvar, RwLock, Once and Parker use `SYS_FUTEX_WAIT` with absolute deadlines (falsification F2).
   - A spurious or timeout return is handled.
   - No lost wakeup between the userspace check and the wait.
6. **Thread exit and TLS.** Key destructors run on thread exit (F1), the TCB and key block are freed after the last
   use, and `ensure_initial_installed` runs before any std or libneo thread is created (F3/F4).
7. **The A4 gate.**
   - It refuses a second template string.
   - The ELF backstop finds every FS- or GS-relative instruction outside `tls::tcb`.
   - The ten C1 syscalls in the manifest each have a negative test.
8. **The scenarios would fail if their claims were false.** `std_threads`' three roles (no cap → 41, 20/20 → 0,
   worker panic → 134), and F5: with the exit-group hook removed, the run times out.
9. **The pitfall bank and prior art.**
   - CP-84 and CP-85 are guarded, with discriminators.
   - CP-86 is accurately OPEN.
   - The prior-art table (std, Hermit, Motor) has licenses, SHAs and dates, and nothing GPL copied.
