# PR #4 Stylo closure review

Reviewer: Chad. Branch: `codex/pr4-review-chad`.
Reviewed head: `f14faff0636e65c2cde6df4e1609131a7382427d`.

- **FAIL — 1. Vendored metadata and licences.** The source crates' manifest metadata and `VENDORED.md` record the reviewed compatible licences, versions, upstream repositories and release commits; no GPL, LGPL or AGPL licence is present (`third_party/ot61-browser/VENDORED.md:68,143-212`). The required `cargo run -p xtask -- vendor-verify` passed: 138 crates, 4,438 files. However, the lockfile also resolves `windows-sys` 0.61.2 to a local stub. Its row explicitly has no upstream repository (`third_party/ot61-browser/VENDORED.md:211`), and the stub manifest has no `repository` field (`third_party/ot61-browser/stubs/windows-sys-0.61.2/Cargo.toml:6-10`). Concrete input: building/resolving `userland/stylo-smoke` includes this stub in its lockfile. The metadata requirement is not met for every resolved crate.
- **FAIL — 2. Stylo build script.** The property generator uses bundled Mako, toml and MarkupSafe imports and contains no network fetch (`third_party/ot61-browser/patched/stylo-0.22.0/properties/build.py:10-18`). It writes generated properties under `OUT_DIR`, but also writes `css-properties.html` and `css-properties.json` under `OUT_DIR/../../../../doc/stylo`, outside `OUT_DIR` (`third_party/ot61-browser/patched/stylo-0.22.0/properties/build.py:70-78`). Concrete input: a normal `stylo` Servo-feature build with Cargo's `OUT_DIR` set; the two doc files are emitted outside that directory. `build.rs` invokes this script at `third_party/ot61-browser/patched/stylo-0.22.0/build.rs:55-70,88-91`; CI's `PIP_NO_INDEX=1` does not change its write locations (`.github/workflows/ot61-closure.yml:119-123`).
- **PASS — 3. `stylo_smoke` oracle.** The expected display, color, font-size and margin values are documented as hand-derived from the literal page and cascade (`userland/stylo-smoke/src/main.rs:106-155`). Assertions compare computed values to the independent `EXPECT` table (`userland/stylo-smoke/src/main.rs:1321-1354`). Coverage includes selector specificity, inline style, author `!important` over normal inline style, inherited color/font size, non-inherited margin, and the 800px media-query branch (`userland/stylo-smoke/src/main.rs:137-149`). This is a fixed-page smoke, not a broad web-platform test suite.
- **PASS — 4. Memory bounds.** The dedicated style thread reserves an 8 MiB stack, below the kernel's 16 MiB per-map/stack ceiling (`userland/stylo-smoke/src/main.rs:1281-1295`; `kernel/src/arch/x86_64/syscall.rs:7089,7397`). The smoke process is given a 256 MiB frame budget (`kernel/src/test_harness.rs:2634-2655`), which bounds memory used by a large document and its allocations. The current page is fixed in the binary (`userland/stylo-smoke/src/main.rs:106-128`): there is no separate hostile-input byte or CPU-time limit in this smoke, so the memory budget is not a parser-work limit.
- **PASS — 5. Default and product images.** The Stylo scenario is opt-in through `neo-test-stylo-smoke` (`kernel/Cargo.toml:441-443`), and only the standalone smoke crates consume the vendored closure (`third_party/ot61-browser/VENDORED.md:27-30`). The diff adds test wiring and the separate closure; it does not alter default or product image composition.
