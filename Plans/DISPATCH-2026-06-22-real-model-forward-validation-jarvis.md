## 0. The decision this build makes
Turn "the mixed-quant forward is proven on hand-laid mini-blocks" into "**the mixed-quant forward produces correct tokens on the real Qwen2.5-0.5B weights**, validated against an independent reference (llama.cpp) on the host" — the de-risking step between F1 (merged) and Stage-B (bare-metal). **No kernel change** (consumes F1 + L2 + L1); **no QEMU**; the 485 MB run is **reported** (the artifact isn't in git), the harness code goes through normal host CI.

## 2. ISCs
- **ISC-1 — Host harness: load the real `.neom`, run the real forward.** Extend `ai-ops-tests` with a validation (behind an **env-var/path gate** — e.g. `NEO_REAL_NEOM=/path/to/qwen0.5b.neom` — so it runs only when the artifact is staged, never in blob-less CI) that: loads the real 485 MB 0.5B `.neom`, builds the model with **`phase9-real-quant`** (F1), and runs **greedy decode for K tokens** (K≈16–32) from a fixed input **token-ID** sequence. **Feed token IDs directly — do NOT depend on the tokenizer (F3 is a separate lane).** 0.5B's hardcoded config matches, so **F2 is not needed** either.
- **ISC-2 — Independent oracle: top-1 parity vs llama.cpp (the correctness proof).** Run the **same source GGUF** through **llama.cpp** (the reference) with the **same input token IDs + greedy (temp 0) decode**, capture its output token-ID sequence. Assert **our greedy output token IDs match llama.cpp's top-1 sequence** for the K tokens (allow the standard divergence point: agreement until the first tie/near-tie; report the first divergence index + the competing logits if any). **Exact-logit match is NOT the bar** — dequant-to-f32 + f32 matmul rounds differently from llama.cpp's in-register quant dot-products; **top-1 token agreement under greedy is the signal.** **Raw-source the reference** — run llama.cpp yourself and capture its tokens; do **not** pull expected tokens through a summarizing/LLM fetch (the byte-oracle acquisition rule). Record the llama.cpp version + exact invocation in the RETURN.
- **ISC-3 — Sanity floors + the discriminator (capture-before-you-need-it).** Regardless of parity: assert **all logits finite** (no NaN/inf) through every layer; assert the decode is **deterministic** across two runs (same seed ⇒ identical tokens). **Log, per forward, which quant dtypes the real model actually exercised** (count of q4_K/q5_0/q6_K/q8_0/f32 tensors hit) — this confirms the q5_0/q6_K/q8_0 paths (133/12/13 tensors) really ran, not just q4_K, and makes a divergence **localizable to a dtype/layer** (if parity breaks, the per-dtype + per-layer log says which quant path diverged). Note the measured per-token latency (D5 sanity — is it the ~0.5–2 s/token band?).
- **ISC-4 — Reported run, not a CI gate.** Because the artifact isn't in git, the 485 MB validation is a **reported dev-container result** (RETURN pastes: the token-ID sequence, the llama.cpp parity result + first-divergence index, the per-dtype exercised counts, finite-logit pass, determinism pass, measured latency) — the same way a bare-metal run is reported. The **harness code** (env-gated) goes through normal host CI (it compiles + its non-artifact unit bits run; the artifact-gated body is skipped when `NEO_REAL_NEOM` is unset). **No QEMU.**
- **ISC-5 — standards.** SPDX on new files. `cargo fmt --all --check` (**run it**), `cargo test --workspace --exclude neoplutarch-kernel`, `cargo clippy --workspace --all-targets -- -D warnings`, kernel clippy — via Docker. No new `unsafe`/invariant. **If the validation finds a real-weight forward bug, STOP and report it** (a fix is a separate follow-on dispatch — don't fold a correctness fix into the validation harness, except a trivial one flagged explicitly).

## 3. Expected-failure-mode analysis (this run must be conclusive on pass AND fail)
- **A quant type's dequant wrong on real data** (mini-fixture didn't catch a real bit pattern) ⇒ parity breaks at the first token through that tensor; the per-dtype/per-layer log localizes it. Most likely failure given F1 only saw hand-laid blocks.
- **NaN/inf from a pathological real block** ⇒ the finite-logit assert fires with the layer index.
- **Shape/stride mismatch on a real tensor** ⇒ load or matmul shape error naming the tensor.
- **Config mismatch** (0.5B hardcoded ≠ the real model's actual dims) ⇒ early shape error; confirms whether F2 is needed sooner than thought.
- **Parity diverges late / near-ties** (legitimate scalar-vs-quant rounding) ⇒ NOT a failure; report the divergence index + that the competing logits were within tolerance (this is the expected honest outcome, per D5/the rounding caveat).

No kernel change, no new invariant/`unsafe`.
