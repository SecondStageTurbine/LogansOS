## Blind-hardware failure-mode / discriminator bank (mandatory — conclusive on pass OR fail)
Extend ADR-077 §Slice-4's bank; every mode maps to the capture channels (serial `REPLY:`/breadcrumbs + the NVMe sink). Design so a FAILURE self-localizes — the base rate in blind bring-up is "the next run reveals the next layer," and **the encoder + 2-D walker have literally never run on real silicon**, so treat first-execution surprises as the expected case:

| Expected failure (even if the primary path is right) | Discriminator (must pre-exist — capture-before-you-need-it) |
|---|---|
| 2-D `local_id` GRF mis-place / walker geometry wrong | `RING_FAULT` **VA decode** (fault address, not just type — ensure the driver logs the address) + known-input `dst` mismatch pattern |
| SIMD32 lane / edge-mask bug | vs the CPU-floor reference; periodic stripes localize the lane stride; edge rows vs interior rows distinguish mask-vs-math |
| Inter-pass flush / MOCS (H→V coherence) | the **`mid` readback oracle after Pass H** (must exist before the run); `mid` OK + `dst` wrong ⇒ flush/MOCS; non-deterministic `dst` across runs ⇒ coherence |
| URB / VFE occupancy misconfig | seqno never retires / partial output ⇒ VFE/URB retune breadcrumb |
| PPGTT binding / A64 stateless fault | `RING_FAULT` VA decode vs the bound operand/kernel/CURBE addresses (the iter4-7 GGTT-vs-PPGTT discriminator) |
| EU dispatch never starts (EOT/thread-count) | seqno stuck at pre-dispatch value + no walker retirement breadcrumb |
| The degrade-to-floor masks a real EU failure | assert the enabled path ACTUALLY dispatched (a compute-admit counter / a "GPU produced dst" flag distinct from the floor) — so "green" can't be the floor silently covering a dead EU |
