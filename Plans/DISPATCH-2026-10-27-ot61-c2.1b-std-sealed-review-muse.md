## Checklist

Answer each item PASS or FAIL with `file:line`. For a FAIL, give a concrete sequence of calls.

1. **No ambient file access.** A process holding no `RootDirCap` can't open, stat, list, create, remove or rename any
   path through std. Name any std or raw syscall path that still reaches the root resolver without the cap.
2. **Sealed handles.** A handle the process was given can be used. A forged handle index, or a handle of another kind,
   is refused. Wrapping a raw handle gives no rights beyond the handle's own.
3. **No leaks through other std surfaces.** `env` is empty and network dial is refused. Say whether `process::Command`,
   `fs::canonicalize`, `current_dir` or temp-dir helpers expose anything.
4. **The test proves the refusals.** `std_sealed` gets all three refusals with no cap, and the twin with a cap can
   open. The fail-closed falsifier (exit 3) would bite.
5. **Coverage.** Name what isn't covered: for example, a content process spawned by a real browser broker, which
   doesn't exist yet.
