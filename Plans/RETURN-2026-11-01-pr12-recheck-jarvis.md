- **PASS — Flow control, page ordering, and deadlock behavior.** The term-page protocol now gives aligned atomic access and Release/Acquire ordering for the size seqlock and mode request/ack (`docs/THINK-2026-10-31-l1a-terminal-window.md:133-164`). The bounded 4 KiB stdin and 64 KiB stdout pipes specify which side blocks, nonblocking terminal writes/reads, EOF/EPIPE, fair 16 KiB drains, and flood/close discriminators (`docs/THINK-2026-10-31-l1a-terminal-window.md:166-197`). A child that stops reading drops terminal input without blocking; a terminal that stops reading applies backpressure to the child; the stated wait/read arrangement leaves the WM servicing other clients.
- **PASS — Key encoding and byte oracle.** The revised table specifies normal and DECCKM arrow/Home/End bytes, function and editing keys, modifiers, all Ctrl+letter bytes and Ctrl+/, plus Ctrl+arrows; hand-laid grid rows cover terminal behavior and answerbacks with exact input/output bytes (`docs/THINK-2026-10-31-l1a-terminal-window.md:332-379`). This closes the former gap where the key encoder and concrete byte/grid expectations were deferred. Remaining per-sequence rows are explicitly L1a.2's deliverable (`docs/THINK-2026-10-31-l1a-terminal-window.md:312-324`), not silently claimed complete here.
- **PASS — Paste and input security.** L1a has no paste source or path, refuses OSC 52, and only writes key-encoder bytes or fixed answerbacks to child stdin. For a later clipboard rung, the design sanitizes controls before adding bracketed-paste markers and supplies KAT vectors for the three injection cases from the prior review (`docs/THINK-2026-10-31-l1a-terminal-window.md:401-463`).
- **PASS — kibi terminal needs.** The protocol now supplies timed reads with distinct bytes/timeout/EOF results, `mode()` and its page word, per-child terminal-state reset, resize polling, handle kinds, and `IsTerminal` (`docs/THINK-2026-10-31-l1a-terminal-window.md:199-267`). The encoder and grid oracle include kibi's control keys, Ctrl+arrows, `ESC[m`, clamped `999C`/`999B`, indexed gutter color and cursor visibility (`docs/THINK-2026-10-31-l1a-terminal-window.md:345-369`). The documented stderr and 100 ms Esc constraints agree with the survey; the L1b gate covers timeout versus EOF, child reset, resize and editing (`docs/THINK-2026-10-31-l1a-terminal-window.md:261-267,474-510`; `docs/THINK-2026-11-01-l1b-kibi-on-logansos.md:217-255`).
