## 0. The decision this build makes
Make natural-language → OS-action **reliable and safe with a fallible 0.5B model**, for the **A1 read/nav tier only** (`ReadFile`, `ListDir`, and the other non-mutating `ActionKind`s). The crux (THINK D1): a **constrained/grammar-guided decode** at the sampling boundary so the model can emit **only** a structurally-valid action AST (or an explicit `clarify`/`no-op`) — converting parse success from ~50% (unconstrained small model) to ~99% structural validity. The keystone (Article 29.3, THINK D3) is **never softened**: the NL layer is UNTRUSTED — it *proposes*; the kernel cap-check *disposes*. A confused/compromised model cannot exceed Arthur's held caps.

## 2. ISCs
- **ISC-1 — Constrained-decode hook (the mechanism, THINK D1/§3.5).** At the **sampling boundary** (the argmax/sample step the agentic generate path uses), apply a **grammar/logit mask** so only tokens that continue a valid action-AST are sampleable. **The engine MATH is frozen** (OT-40/OT-37 forward unchanged) — this masks logits *before* the existing argmax, it does not change the forward. Expose the per-step logits to the masker for the agentic path only (THINK §3.5: a contained change to the generate output contract, gated to the agentic feature). Pure CPU at the sample step; no governance lock, no DMA.
- **ISC-2 — The A1 action grammar (THINK §3.4).** A grammar over the **read/nav tier** of the existing `ActionKind`s (`ReadFile`, `ListDir`, … — the non-mutating subset), **parameterized at runtime** by (a) the available action set and (b) the held grant/cap set, plus an explicit **`clarify`** and **`no-op`** production. The model can emit only: a valid read/nav action AST, a clarify question, or a no-op. **Independent byte-oracle:** a hand-laid example of the action-AST encoding (the grammar's output structure) asserted against the parser, per the byte-oracle rule (round-trip alone insufficient).
- **ISC-3 — NL → action → cap-check → NL result (A1 executes directly, THINK D2/A1).** Wire the constrained-decoded action through the **unchanged `execute_action()` cap-check** → run the syscall (read/nav only) → render the result back as NL. A1 executes directly (no confirmation/reversibility — that's A2/A3, a later slice, because read/nav is reversible+low-stakes by construction).
- **ISC-4 — The safety net is the boundary (THINK D3, the keystone).** The cap-check is the only authority. Enumerate + test the failure modes: malformed/hallucinated AST → **impossible** (grammar-constrained); valid action for an **ungranted** resource → **cap-check DENIES**, surfaced with the specific missing capability (OT-18 on-miss re-request); semantically-wrong-but-granted read → harmless wrong result, **never silent corruption**. Prove "safe to be wrong" by failure-mode enumeration, not by trusting the model.
- **ISC-5 — Clarify branch (THINK D4).** The grammar includes a `clarify` production so the model *can* ask instead of guessing. (Honest: small models are overconfident and often won't — the backstop is ISC-4's cap-check; clarify improves UX when used, safety holds when not.)
- **ISC-6 — Kill-switch + coexistence.** `agentic-actions` **default-off** ⇒ bit-for-bit the **current** behavior (the existing `respond_to_turn_with_actions` Hermes free-form path stays the fallback; `neo>` deterministic commands unchanged). Equality regression proving OFF ≡ today. The `neo>` command floor and `arthur>` NL coexist (THINK D5).
- **ISC-7 — standards.** SPDX; `cargo fmt --all --check`; clippy `-D warnings` (kernel blocking) via Docker. No new cross-cutting invariant. Any new `unsafe` justified.

## BOUNCE 2026-06-26 (PM, AAG) — the safety half is excellent + verified; the model isn't actually driving the decode

The `22a8e80` RETURN is **safe and the gate is honest** — AAG cleared three lenses:
- **Keystone (29.3): clean.** Every model→effect path routes through the unchanged default-deny `execute_action_with` cap-check; the agentic executor has **no Write/Spawn arm** (grammar = ReadFile/ListDir/Clarify/NoOp only, available set = {ReadFile, ListDir}); `action.rs`/`grant_store.rs` are bit-identical (not in the diff); the new `SYS_GENERATE_CONSTRAINED` syscall returns tokens only and grants no authority; path-traversal rejected. A jailbroken model cannot exceed held caps.
- **Memory-safety: clean.** Both new `unsafe` blocks sound (`validate_user_buf` + `checked_mul`); untrusted-token AST parser bounds-safe (fields ≤128B, traversal blocked).
- **Completeness/kill-switch: clean, no overclaim.** Default-off ≡ prior (additive cfg-out); the scenario is non-vacuous (granted-executes / ungranted-DENIED-with-missing-cap / mutation→clarify / garbage→rejected); the byte-oracle is a real hand-laid literal.

**The blocker (logit-mask lens, high confidence) — A1's core deliverable is not met.** The "grammar-constrained decode" is **degenerate**: `agentic_candidate_asts` emits exactly **one** AST from a userland rule-based heuristic (`choose_agentic_action`), and `constrained_argmax_token` forces that lone sequence token-by-token — so **the model's forward runs and its logits are causally ignored; a keyword heuristic, not the model, picks the action + its path argument.** That is not the OT-26 D1 mechanism this dispatch is built around (§0: "the constrained/grammar-guided decode so the **fallible model** can emit a valid action AST"). The agentic layer's whole value — the model understanding arbitrary NL intent (incl. extracting the path) — is absent; a brittle heuristic stands in. The masking *math* is sound and the safety is real, but the build delivers A1's **scaffolding + a heuristic**, not A1.

### Fix (the bounce) — narrow, because the safe half is verified-done
- **ISC-F1 (the deliverable):** make the constrained decode **model-driven**. Build the candidate set from the **valid grammar productions** (read/list with the model emitting the path tokens), mask the logits to the set of valid continuations at each step, and let the **MODEL's masked logits select** among them (the D1 mechanism). The model — not `choose_agentic_action` — must determine which valid AST emerges and its arguments. (If a heuristic remains as a fallback, it must be exactly that — a fallback when the model stalls — not the primary chooser.)
- **ISC-F2 (prove the model drives it):** the QEMU scenario must prove the **model's output** determines the action — e.g. two prompts that the heuristic would map identically but the model distinguishes, or assert the emitted AST tracks the model's logits (not a constant). Today's scenario passes trivially because the AST is heuristic-determined; it must fail if the model is ignored.
- **Keep (verified clean, do not redo):** the cap-check keystone wiring, the `SYS_GENERATE_CONSTRAINED` syscall + mask plumbing, the AST grammar + byte-oracle, the kill-switch, the failure-mode coverage. Only the candidate-generation (single-heuristic → model-over-valid-set) and its proof change.
- Re-gate: 4-shard QEMU + AAG (the new AAG only needs the logit-mask + completeness lenses re-run on the model-driving delta; keystone/memsafety are unchanged).
