4. **FAIL F1 for the plan's fail-closed descriptor validation; the four intended sequence differences themselves are sound.**

   The full second PM1 write preserves the chosen SLP_TYP and SCI_EN (`power_logic.rs:202`) instead of replacing the type with zero on retry. Requiring both hardware-reduced registers matches [ACPICA's pinned extended-sleep implementation](https://github.com/acpica/acpica/blob/e85aa3be/source/components/hardware/hwesleep.c#L84). Width-zero fallback to PM1_CNT_LEN is consistent with [ACPICA's FADT compatibility handling](https://github.com/acpica/acpica/blob/e85aa3be/source/components/tables/tbfadt.c#L555). Reading PM1b's own base preserves its own unrelated bits while giving it its own SLP_TYP; no shared OR value is required to preserve per-register reserved bits. The type/enable locations and the requirement for 8-bit, offset-zero sleep registers are specified in [ACPI 6.5 §4.8.3](https://uefi.org/specs/ACPI/6.5/04_ACPI_Hardware_Specification.html#sleep-control-and-status-registers). ACPICA's ten-second SLP_EN retry is visible in [hwsleep.c](https://github.com/acpica/acpica/blob/e85aa3be/source/components/hardware/hwsleep.c#L137); this review does not claim P1 executes or times that retry.

   **Concrete failed input:** a 276-byte FACP, HW_REDUCED_ACPI set, SLEEP_CONTROL at offset 244 with `{space=SystemIO, width=16, bit_offset=8, access_size=0, address=0x1804}`, and SLEEP_STATUS at offset 256 with `{space=SystemIO, width=8, bit_offset=0, address=0x1800}`; _S5 decodes to 7/0. `parse_fadt` preserves the descriptor; `plan_power_off`'s usable predicate at `:303` checks only address space, returning HwReduced with value 0x3c instead of SafeToTurnOff. ACPI requires these registers to be eight bits with zero bit offset. A raw byte write cannot honor this descriptor's shifted field. The paired-register KAT (`src/tests.rs:884`) tests presence/space but omits width/offset negatives. Independently compiled and ran `target/review-janus/p1_bad_gas.rs` against the exact pinned module: it printed this HwReduced plan and failed the expected-fail-closed assertion. Validate both descriptors' supported geometry before constructing a usable plan. Main's later address-range checks do not validate these width/offset fields either; this finding is not merely a historical P1 address-range omission. P1 itself still performs no hardware access.
